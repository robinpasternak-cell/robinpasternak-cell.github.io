Shorts Bot

Shorts Bot ist ein privates Werkzeug von Robin Pasternak, das automatisch erstellte Kurzvideos auf den eigenen YouTube-Kanal hochlädt.

Shorts Bot nutzt die YouTube API Services (Uses YouTube API Services). Es gelten die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung.
