Datenschutzerklärung

Shorts Bot wird ausschließlich von Robin Pasternak für den eigenen YouTube-Kanal genutzt.

Die Anwendung nutzt die YouTube Data API nur, um selbst erstellte Videos auf diesen Kanal hochzuladen. Es werden keine personenbezogenen Daten Dritter erhoben, gespeichert oder weitergegeben. Zugangsdaten werden ausschließlich verschlüsselt als Secrets im privaten Code-Repository des Betreibers gespeichert.

YouTube API Services

Shorts Bot nutzt die YouTube API Services. Mit der Nutzung stimmst du den YouTube-Nutzungsbedingungen zu. Es gilt die Google-Datenschutzerklärung.

Verwendet wird ausschließlich die Berechtigung zum Hochladen von Videos (youtube.upload). Es werden keine Kanal-, Nutzer- oder Analysedaten von YouTube abgerufen oder gespeichert.

Speicherung und Löschung

Gespeichert wird nur ein OAuth-Aktualisierungstoken als verschlüsseltes Secret im privaten Repository des Betreibers. Es wird gelöscht, sobald der Zugriff widerrufen wird oder spätestens 30 Tage nach Einstellung der Nutzung.

Zugriff widerrufen

Der Zugriff kann jederzeit über die Google-Sicherheitseinstellungen widerrufen werden.
